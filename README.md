# 3D Low-Poly Diorama Portfolio & CV Website

An interactive, production-ready 3D portfolio and CV website inspired by playful RPG / low-poly diorama aesthetics, built with Three.js (ES Modules) and vanilla web technologies. Ready for instant deployment to GitHub Pages with zero bundlers or build steps.

## ✨ Features
- **Central Floating Island Diorama:** Ultra low-poly, single-color flat-shaded 3D island featuring a cozy workshop cabin, wizard tower, animated cascading waterfall, campfire with embers, treasure chests, and companion NPCs.
- **Scroll-Driven Camera Choreography:** Smooth camera waypoints interpolating through diorama landmarks corresponding to each CV section.
- **Tactile RPG Game UI:** Diegetic wooden signboard buttons (`PLAY / Portfolio`, `ABOUT`, `MESSAGE / Contact`, `RESUME / Download CV`), hanging medieval guild banners, and metal chain links.
- **Interactive 2.5D Mascot:** Wizard companion that tracks your cursor and speaks funny RPG dialogue on click.
- **Procedural Web Audio API:** Synthesized wooden knocks, clicks, parchment rustles, and spell chimes with zero audio files.
- **Single-File Data Source (`data.json`):** Easy updates for profile details, education, experience timeline, skills, and projects.
- **Custom Model Override:** Set `CUSTOM_ISLAND_MODEL_PATH = "./assets/island.glb"` in `app.js` to drop in your own 3D model anytime.

## 🚀 Instant Deployment (GitHub Pages)
1. In your GitHub repository, go to **Settings** > **Pages**.
2. Under **Build and deployment**, select **Deploy from a branch** and choose `main` branch root (`/`).
3. Your 3D portfolio will be live at `https://<your-username>.github.io/3d-portfolio-2/`!
